# Colorful Snake Game

Welcome to the Colorful Snake Game! This is a fun and engaging browser-based game designed for kids and adults alike. Customize your snake, choose difficulty levels, and enjoy a playful gaming experience.

## How to Play
1. Use the arrow keys or swipe gestures to control the snake's direction.
2. Eat the food to grow your snake and increase your score.
3. Avoid colliding with walls, obstacles, or yourself.
4. Choose from three difficulty levels: Easy, Medium, and Hard.
5. Customize your snake's color using the color picker.

## Features
- Bright and colorful design appealing to children.
- Responsive layout for desktop and mobile devices.
- Difficulty levels with optional obstacles.
- Power-ups for special abilities.
- High score tracking using localStorage.
- Smooth animations and visual effects.

## Technical Details
- Built with HTML5, CSS3, and JavaScript.
- Canvas API for rendering the game board and elements.
- LocalStorage for high score persistence.
- Responsive design with touch controls for mobile users.
